# Daily Predict

A World App Mini App where verified humans make one daily prediction, competing to see who can forecast outcomes most accurately. Top predictors win WLD rewards.

**Personal project** (separate from Human Poll / Luxates LLC).

---

## Concept

- One binary prediction question per day, auto-generated by Claude Haiku
- World ID authentication = zero bots, one vote per human per day
- Real-time result breakdown after voting
- Streak tracking, leaderboard, gamification badges
- Phase 2+: Daily WLD prize drawn from Developer Rewards revenue

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 15, React 19, TypeScript, Tailwind CSS |
| Mini App SDK | @worldcoin/minikit-js, @worldcoin/mini-apps-ui-kit-react |
| Backend | Supabase (PostgreSQL, Row-Level Security) |
| Question Generation | Claude API (Haiku) via Vercel Cron |
| Result Verification | CoinGecko API, OpenWeather API, manual fallback |
| Hosting | Vercel (personal, free tier) |
| Auth | World ID via MiniKit SDK |

## Setup

### 1. Prerequisites

- Node.js 20+
- A Supabase project (create at supabase.com)
- A World Developer Portal App ID (personal team)
- An Anthropic API key

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment

```bash
cp .env.local.example .env.local
# Fill in your keys
```

| Variable | Description |
|----------|-------------|
| `NEXT_PUBLIC_WLD_APP_ID` | World App ID from Developer Portal |
| `NEXT_PUBLIC_WLD_ACTION` | World ID action name (`daily-predict-verify`) |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon key |
| `ANTHROPIC_API_KEY` | Claude API key for question generation |
| `CRON_SECRET` | Random secret to secure cron endpoints |

### 4. Initialize database

Run the migration in your Supabase project's SQL editor:

```bash
# Via Supabase CLI
supabase db push

# Or manually paste supabase/migrations/20260401_initial.sql into the SQL editor
```

### 5. Run locally

```bash
npm run dev
# Open http://localhost:3000?app=1 to see the Mini App UI
```

## Cron Jobs (Vercel)

| Endpoint | Schedule | Purpose |
|----------|----------|---------|
| `/api/cron/generate-prediction` | `0 21 * * *` (UTC) | Generate tomorrow's question at 6am JST |
| `/api/cron/resolve-predictions` | `0 22 * * *` (UTC) | Resolve yesterday's prediction at 7am JST |

All cron requests require `Authorization: Bearer $CRON_SECRET` header.
